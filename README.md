# Портфолио AI-автоматизатора

Лэндинг с кейсами по AI-автоматизации бизнес-процессов: AI-агенты на n8n, Telegram-боты, генерация документов, транскрибация, контент-заводы.

Сайт: <https://forumgm18.github.io/avs-portfolio-ai/>

## Структура

| Путь | Что лежит |
|---|---|
| `index.html` | страница, контент рендерится из `data/cases.json` |
| `data/cases.json` | профиль, тексты кейсов, списки доказательств |
| `assets/css/base.css` | раскладка и компоненты |
| `assets/css/theme.css` | цвета и шрифты, светлая и тёмная тема |
| `assets/js/app.js` | рендер, лайтбокс, просмотр конспектов |
| `assets/js/wf-viewer.js` | просмотрщик n8n-воркфлоу из JSON (SVG, без зависимостей) |
| `cases/<slug>/` | оптимизированные медиа, очищенные JSON воркфлоу, PDF, конспекты |
| `certificates/<направление>/` | сертификаты курсов в WebP |
| `tools/` | скрипты подготовки медиа и чистки JSON |

## Добавить или обновить кейс

1. Положить исходники в `Кейсы/<папка кейса>/` (папка в git не попадает).
2. Добавить обработку в `tools/build-media.sh` и запустить из корня сайта:

   ```bash
   bash tools/build-media.sh
   ```

3. Очистить JSON воркфлоу от credentials и служебных id:

   ```bash
   node tools/sanitize-n8n.mjs "Кейсы/<папка>/<workflow>.json" cases/<slug>/workflow.json
   ```

4. Описать кейс в `data/cases.json`: тексты, метрики, пути к медиа (без расширения `.webp` в галерее — превью `-thumb.webp` подставляется само).

Нужны `magick` (ImageMagick с WebP), `ffmpeg`, `node`.

## Добавить сертификат

1. Положить файл (jpg или png) в `Курсы/<направление>/` (папка в git не попадает).
2. Для нового направления добавить строку в `CERT_DIRS` в `tools/build-media.sh`, например `[AI]=ai`, и запустить скрипт.
3. Добавить запись в `certificates` в `data/cases.json`: группа, путь без расширения, название курса, организатор, период.

## Локальный запуск

Страница грузит данные через `fetch`, поэтому нужен HTTP-сервер, а не `file://`:

```bash
python3 -m http.server 8765
```

Затем открыть <http://localhost:8765/>.
